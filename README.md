# IoT Fire Detection System

## Overview
An IoT-based fire detection system designed to monitor fire and smoke levels using ESP32 and send real-time alerts.

## Features
- Fire detection
- Smoke monitoring
- ESP32 Wi-Fi connectivity
- Real-time monitoring
- Alarm system

## Hardware
- ESP32
- Flame Sensor
- Smoke Sensor
- dht11 sensor
- Buzzer
- LEDs

## Software
- Arduino IDE
- blynk.iot
- ESP32
- C++
